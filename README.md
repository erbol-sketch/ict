# Презентация: Развитие технических средств ИКТ

10 слайдов: 1–5 — 3D-комната, 6–10 — облачная гора. После 5-го камера влетает в картину на потолке, белая вспышка — и плавный переход в облака.

## Запуск
```
npm install
npm run dev     # http://localhost:3000
```
Управление: стрелки ←/→, пробел, точки и кнопки внизу справа.

## Что менять
- `components/slides.js` — тексты слайдов и точки камеры (`cameraPoints`).
- `cameraPoints` — камера в комнате (слайды 1–5), `cloudPoints` — камера над горой (слайды 6–10).
- Слайд с `scene: 'clouds'` показывается на фоне облаков.
- Модели: `public/room.glb`, `public/cloudy_mountain.glb`.
- Подбор ракурса: `/?scene=clouds&cam=128,30,44&look=124,15,-2`.
